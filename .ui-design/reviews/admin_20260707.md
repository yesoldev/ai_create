# Design Review: Admin.tsx (Phase 4 관리자 화면)

**Target:** frontend/src/pages/Admin.tsx · **Platform:** 반응형 light/dark · **사용자:** 관리자(운영자)
**근거:** 코드 + admin.png + 백엔드 실플로우 검증

## Summary
계정 목록·추가·사용중지/재개·월 한도 변경·무제한 토글·전체 사용액을 카드형으로 명확히 제공. Iconify(이모지 0), 큰 버튼. 관리자 대상이라 정보 밀도는 조금 높아도 무방. 크리티컬/메이저 없음.

## Notes / Suggestions
- 이메일 검증: `.local` 등 특수 도메인은 백엔드(email-validator)가 거부 → 실제 회사 도메인 이메일로 생성해야 함(운영상 정상). 필요 시 폼에 안내 문구 추가 고려.
- 계정 삭제는 없음(계획대로 "사용 중지"만) — 의도된 설계.
- 무제한 해제 시 기본 한도 15,000원으로 설정(백엔드 "변경 없음" 400 회피).

## Positive
- 역할 뱃지(관리자)·상태 뱃지(사용 중지) 시각적 구분
- 사용/한도 한 줄 요약, 진행 액션마다 안내 메시지
- 활성 토글·한도 저장·무제한 각각 독립 버튼(오작동 위험 낮음)

## 검증
- 백엔드 실플로우: 생성→목록→비활성→한도변경→무제한→정리삭제 전부 200 (테스트 계정 삭제 완료)
- Playwright E2E(모킹): 목록 렌더·계정추가 POST·상태변경 PATCH 발생 확인
