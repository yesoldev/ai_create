# Design Review: Editor.tsx (Phase 3 편집기 MVP)

**Target:** frontend/src/pages/Editor.tsx · **Platform:** 반응형 light/dark · **사용자:** 60대 초보
**근거:** 코드 + editor-final.png(화면) + export-final.png(실제 저장물)

## Summary
생성한 이미지 위에 글자·도형을 얹고 원본 해상도로 저장하는 편집기. 큰 라벨 버튼, Iconify(이모지 0), 되돌리기/다시. Fabric 이미지 렌더 버그(0.5배)를 **합성 방식**(이미지=CSS 배경, Fabric=투명 오버레이, 저장 시 원본해상도 합성)으로 우회. 크리티컬/메이저 없음.

## Notes
- **핵심 버그 해결**: FabricImage.fromURL이 이미지를 0.5배로만 렌더(원인 미상, 로딩 방식 무관). → AI 이미지는 Fabric에 넣지 않고 컨테이너 CSS 배경으로 깔고, 저장 시 offscreen 캔버스에 원본이미지+Fabric오버레이 합성. 화면/저장 모두 정확 검증.
- 저장은 원본 해상도(PNG/JPG). JPG는 흰 배경 채움.

## Suggestions (추후)
- 글자 "크게/작게" 버튼(현재는 모서리 드래그로 크기 조절 — 초보는 모를 수 있음)
- 기본 글자 위치를 살짝 안쪽으로(현재 왼쪽 끝에 근접)
- 자르기(crop), px/mm/cm 캔버스 크기 입력(계획 §3.3) — MVP 이후

## Positive
- 큰 버튼+라벨, 색상 선택 즉시 반영, 삭제/되돌리기/다시 명확
- 원본 해상도 저장(인쇄 품질 유지)
- 스튜디오 결과 "글자 넣고 꾸미기"에서 자연스럽게 진입

## 검증
- Playwright E2E: 결과→편집→글자추가→되돌리기(활성화 토글)→PNG 저장(다운로드) 통과
- 실제 저장 합성물(export-final.png) 육안 확인: 전체 이미지 + 오버레이 정확
