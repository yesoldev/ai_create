# Design Review: 스튜디오 5단계 '그림 자유도'

**Target:** frontend/src/pages/Studio.tsx (자유도 카드 + FreedomLine), frontend/src/lib/studio.ts (FREEDOMS 문구)
**Platform:** 반응형 light/dark · **사용자:** 50대 초보(나이든 사용자)
**근거:** 코드 + 스크린샷 4종(shots/freedom_desktop·_wild·_mobile·_dark.png) + 실제 생성물 4장 비교 + E2E 18/18

## Summary
"매번 비슷한 그림이 나온다"를 해결하려 자유도 3단계를 5단계(이대로 만들까요?)에 추가했다.
카드 선택 → 아래 설명 패널이 즉시 바뀌는 구조. 크리티컬 없음, 메이저 4건은 리뷰 중 즉시 수정 완료.
남은 것은 이 화면 밖의 구조적 이슈(Iconify 런타임 로딩) 1건.

**Issues:** Critical 0 · Major 4(수정완료) · Minor 2(수정완료) · Suggestion 2(미적용)

## Major — 수정 완료

### 1. 조사 오류 "‘적당히 다르게’을(를) 고르면"
- **문제:** 관공서 문서식 `을(를)` 병기. 나이든 초보 사용자에게 읽기 부담.
- **조치:** `josa(word, "을/를")` 헬퍼 추가(받침 판정). → "‘적당히 다르게’를 고르면".
  라벨을 나중에 추가해도 깨지지 않는다.

### 2. 설명 본문 글씨가 화면 기준보다 작음
- **문제:** 패널 본문만 `text-base`(16px). 이 앱은 본문 `text-lg`(18px) 기준.
- **조치:** `text-lg` + 제목 `text-xl font-bold`, 아이콘 24→26px.

### 3. "위의 배치·빛에 더해" 지시어 모호
- **문제:** 모바일에서 카드가 세로로 쌓이면 '위의'가 바로 위 카드('적당히 다르게'가 아닌 것)로 읽힌다.
- **조치:** "‘적당히 다르게’에서 바뀌는 배치·빛에 더해" 로 대상 명시.

### 4. 선택 변경이 스크린리더에 전달되지 않음
- **문제:** 카드를 눌러도 패널 내용 교체를 보조기술이 알리지 않음.
- **조치:** 패널에 `aria-live="polite"`. (카드는 기존 `aria-pressed` 유지)

## Minor — 수정 완료

### 5. 데스크톱 3열에서 카드 설명이 지저분하게 줄바꿈
- **문제:** 열 폭 ~138px라 "무난하고 예상되는 / 그림"처럼 어색하게 끊김.
- **조치:** 3열(`sm:grid-cols-3`) 폐기, 항상 전체폭 1열. 큰 버튼 원칙에도 부합.

### 6. 다크모드에서 설명 패널 경계가 거의 안 보임
- **조치:** `border-emerald-900/50 → 800/70`, `bg-emerald-950/20 → /30`.

## Suggestions — 미적용

### 7. Iconify 런타임 원격 로딩 (이 화면 밖 · 앱 전체)
`@iconify/react`만 의존성에 있고 `@iconify/json`·`addCollection`이 없다.
아이콘 데이터를 api.iconify.design에서 매번 받아오는 구조라, 실제로 스크린샷 첫 촬영에서
아이콘이 통째로 비어 나왔다(2.5초 대기 후 정상). 사내망·오프라인이면 전 화면 아이콘이 사라진다.
이모지 금지 정책상 아이콘이 유일한 시각 기호이므로 영향이 크다. → 별도 작업으로 번들링 권장.

### 8. 자유도와 비용의 관계
자유도는 비용에 영향이 없는데 "매번 새롭게"가 비싸 보일 수 있다.
바로 아래 예상비용 바가 같은 금액을 유지해 사실상 해소되므로 문구 추가는 보류.

## Positive
- 참고 이미지가 있으면 자유도 칸 자체를 숨김 — "비슷하게"와 "다르게"의 모순을 UI에서 제거
- "안정적으로"가 기존 동작과 완전히 동일(변주 문구 미주입) — 기존 사용자 경험 보존
- 요약표에 "자유도" 행 노출 — 만들기 직전 최종 확인 가능
- 바뀌는 것 / 바뀌지 않는 것 / 이럴 때 고르세요 3단 구조 — 초보자가 인과를 이해할 수 있음
- Iconify만 사용, 이모지 0

## 검증
- 실제 생성 4장: 안정적으로 ×2는 골격 동일(파란 방사형 배경·같은 글자 배치), 매번 새롭게 ×2는 완전히 다른 시안 → 기능 실효 확인
- E2E 18/18 통과 (자유도 2건 신규)
- 타입체크·빌드 통과, light/dark/모바일 스크린샷 확인
