# Design Review: Library.tsx + 편집기 저장 (Phase 4 보관함/재사용)

**Target:** frontend/src/pages/Library.tsx, Editor 저장 · **Platform:** 반응형 light/dark · **사용자:** 60대 초보
**근거:** 코드 + library.png + 백엔드 실플로우 검증

## Summary
편집기 "보관함에 저장"(이름 입력) → 보관함 썸네일 그리드 → 클릭 시 편집기에서 배경+오버레이 복원(재사용). 요구사항 4-b("열면 텍스트/색/일러스트 바꿔 재사용") 충족. Iconify(이모지 0), 큰 카드. 크리티컬/메이저 없음.

## 동작
- 저장: 편집기 → 이름 모달 → POST /api/templates{canvas_json(오버레이), generation_id}. 백엔드가 generation_id로 원본(results)·썸네일(thumbs) 경로 자동 연결.
- 재사용: GET /api/templates/{id} → bg_url(원본 서명URL) + canvas_json → 편집기가 배경 이미지 + 오버레이 복원.
- 지우기: 확인창 후 삭제.

## Suggestions (추후)
- 트리(카테고리>업체명) 폴더 구조는 미구현(현재 평면 목록). folders API는 백엔드에 있음 → 다음 단계.
- 이름 변경/이동/복제 UI(백엔드 copy/patch 있음).
- 저장 시 오버레이 포함 썸네일 별도 생성(현재는 원본 썸네일 사용).

## Positive
- 재사용 루프 완결, "글자만 바꿔 재사용" 안내로 목적 명확
- 큰 썸네일 카드, 열기/지우기 분리(오작동 위험 낮음), 로딩 스피너
- 삭제 확인창(파괴적 동작 보호)

## 검증
- 백엔드 실플로우: 저장(생성물 연결)→목록(thumb_url)→상세(bg_url+canvas_json)→삭제 전부 200
- Playwright E2E: 편집기 저장→보관함 목록→다시 열기 통과. 전체 8/8.
