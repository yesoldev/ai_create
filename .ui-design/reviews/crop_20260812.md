# Design Review: 편집기 '이미지 자르기'

**Target:** frontend/src/pages/Editor.tsx (자르기 버튼·자르기 바·오버레이·확인 다이얼로그), frontend/src/lib/library.ts(replacePageImage), backend/routers/templates.py(PUT /pages/{id}/image)
**Platform:** 반응형 light/dark · **사용자:** 60대 초보
**근거:** 코드 + 스크린샷 4종(shots/crop_desktop·_dark·_mobile·_confirm.png) + E2E 3건(crop.spec.ts)

## Summary
생성된 페이지 이미지를 편집기에서 직접 자르는 기능. 도구모음 [자르기] → 그림 위에 남길 영역을
정하고 [이 부분만 남기기]. 자른 결과는 서버에 새 이미지로 저장되고 글자·도형 오버레이도 같이 이동한다.
크리티컬 0건, 메이저 2건·마이너 3건은 리뷰 중 즉시 수정 완료. 남은 건 제안 2건.

**Issues:** Critical 0 · Major 2(수정완료) · Minor 3(수정완료) · Suggestion 2(미적용)

## Major — 수정 완료

### 1. 자르는 중에도 편집·내려받기 버튼이 살아 있음
- **문제:** 자르기 오버레이가 떠 있는 상태에서 [글자 넣기]·[네모]를 누르면 오버레이 아래에 객체가
  추가되고(보이지 않음), [PNG]를 누르면 **자르기 전 그림**이 내려받아진다. 페이지 썸네일을 눌러
  다른 페이지로 넘어가면 자를 영역 좌표가 이전 페이지 기준으로 남아 엉뚱하게 잘린다.
- **조치:** `cropOn`인 동안 글자/네모/동그라미/색/채우기/크게/작게/삭제/되돌리기/다시,
  PNG·JPG·전체ZIP·AI로 수정, 페이지 전환·페이지 삭제를 모두 `disabled` 처리.
  자르기는 "지금은 자르는 중"이라는 상태가 화면에서 분명해졌다(도구가 흐려짐 + [자르기] 버튼 강조).

### 2. 모바일에서 정작 자를 그림이 화면 밖에 있음
- **문제:** 390px 폭에서 헤더+도구모음+자르기 바가 화면을 다 채워 **그림과 자르기 네모가 첫 화면에
  보이지 않는다.** 스크롤해 그림을 보면 이번엔 [이 부분만 남기기] 버튼이 화면 위로 사라진다.
- **조치:** ① 자르기를 켤 때 그림 영역을 화면 가운데로 `scrollIntoView`,
  ② 자르기 바를 `sticky top-0 z-30`으로 고정(다크에서 비치지 않게 배경 불투명도 상향).

## Minor — 수정 완료

### 3. 확인 문구의 조사 띄어쓰기 ("819×320px 만 남아요")
- **조치:** "819×320px**만** 남고 나머지는 잘려 나가요."로 수정. 무엇이 사라지는지도 함께 명시.

### 4. 밝은 그림 위에서 자를 영역 테두리가 안 보임
- **문제:** 테두리가 흰색뿐이라 흰 배경 배너에서 경계가 사라진다.
- **조치:** 흰 테두리 + 바깥 검은 선(shadow) + 안쪽 검은 선(`ring-inset ring-black/45`).

### 5. 크기 변화가 보조기술에 전달되지 않음
- **조치:** '자른 크기 000×000px' 칩에 `aria-live="polite"`, 자를 영역에
  `role="group"` + 조작법을 담은 `aria-label`.

## Suggestion — 미적용

### 6. 키보드만으로는 자를 수 없다
방향키로 네모를 옮기고 Shift+방향키로 크기를 바꾸는 조작이 있으면 좋다. 현재 사용자층(마우스·터치
중심)과 다른 화면(편집기 자체가 드래그 기반)을 고려해 이번엔 넣지 않았다.

### 7. 되돌리기 불가 → **해결됨(2026-08-12)**
사용자 요청으로 자른 결과를 **새 페이지로 추가**하도록 바꿨다(`POST /api/templates/{tid}/pages/image`).
원래 페이지가 그대로 남아 자르기 전으로 언제든 돌아갈 수 있고, 확인 문구도
"새 페이지로 추가돼요. 지금 페이지는 그대로 남아요."로 바뀌었다.

## Positive Observations
- 프리셋을 비율(4:3) 대신 **자유롭게/정사각형/가로형/세로형**이라는 말로 제시 — 나이든 사용자에게 읽힌다.
- 모서리 손잡이 28px 원형(권장 최소 24px 초과), 자를 영역 안은 어디를 잡아도 이동.
- 삼분할 안내선으로 구도를 잡을 수 있다.
- 자른 결과 크기를 px로 항상 보여줘 인쇄 판단이 가능.
- 이모지 없이 Iconify(ph:crop-*)만 사용 — 프로젝트 규칙 준수.
- AI 호출이 없어 **무과금**. 실패 시 안내도 한글(errorInfo 재사용).
