## Summary

새 화면들은 기존 디자인(emerald 강조, rounded-2xl, border-2, 큰 글씨, Iconify)과 일관되고 이모지가 없다.
리뷰 도중 E2E가 **상단 알림이 떠 있는 방식이라 편집기 머리글의 '보관함에 저장' 버튼을 가린 문제**를 잡아,
알림을 화면 맨 위에 자리를 차지하는 띠로 바꿨다. 아래 지적 사항은 모두 반영 완료.

## Critical Issues

### Issue 1: 상단 알림이 페이지 버튼을 가림 — 해결
**Location:** `JobsUI.tsx` JobsBar · **Category:** Usability
떠 있는(fixed) 알림이 편집기 머리글 가운데~오른쪽 버튼(보관함에 저장 등)을 덮어 누를 수 없었다(E2E `library.spec` 실패로 발견).
**조치:** 문서 흐름 안의 전체 너비 띠로 변경 → 내용이 아래로 밀려 아무것도 가리지 않는다. 모든 페이지가 `min-h-screen`이라 레이아웃 영향 없음.

## Major Issues

### Issue 2: 터치 화면에서 돋보기가 보이지 않음 — 해결
**Location:** `JobsUI.tsx` JobCard · **Category:** Usability
돋보기가 마우스를 올려야만 보여, 태블릿 사용자는 확대 기능을 알 수 없다.
**조치:** `pointer-coarse:` 변형으로 마우스 없는 기기에서는 늘 보이게(빌드 CSS에 `pointer:coarse` 확인).

### Issue 3: 실패한 작업을 다시 할 방법이 없음 — 해결
**Location:** `JobsUI.tsx` 실패 카드, `lib/jobs.tsx` · **Category:** Usability
초보 사용자가 처음부터 다시 입력해야 했다.
**조치:** 실패 카드에 큰 버튼 **'같은 내용으로 다시 만들기'** — 작업 내용을 기억해 그대로 다시 실행(E2E로 확인).

### Issue 4: 패널 카드가 원본 이미지(수 MB)를 불러옴 — 해결
**Location:** `JobsUI.tsx` JobCard · **Category:** Performance
**조치:** 카드는 가벼운 썸네일(`thumb_url`, 없으면 원본으로 대체), 원본은 확대 팝업에서만. `loading="lazy"`.

## Minor Issues

### Issue 5: 패널을 열어도 키보드 포커스가 패널 밖에 남음 — 해결
**조치:** 열리면 '닫기' 버튼으로 포커스(숨김→보임 전환 뒤에 주도록 지연). Esc로 닫힘.

### Issue 6: 관리자 '자세히 보기' 머리글 버튼 4개가 좁은 화면에서 넘침 — 해결
**조치:** `flex-wrap`.

## Suggestions

### Suggestion 1: 만드는 중 카드에 예상 시간 — 반영
'만드는 중 · 12초 (보통 30초쯤)' — 기다림이 덜 불안하다.

### Suggestion 2 (보류): 관리자 모델별 예상 비용
관리자가 2.5 모델을 골라도 예상 비용이 기본 모델 기준(약 70원)으로 보인다. 실측은 2.5가 약 1/4.
관리자 전용·무제한 계정이라 영향이 작아 보류. 필요 시 `cost.estimate_cost_krw`에 모델별 계수 추가.

## Positive Observations

- 알림 문구가 쉬운 한글("AI가 1개 만드는 중 · 1개 완성", "1개 실패했어요")이고 버튼이 모두 h-12 이상.
- 진행 막대에 `role="progressbar"`·`aria-valuenow`, 알림 띠에 `aria-live="polite"`.
- 편집기에서 작업 중에도 계속 편집 가능 + 버튼이 돌며 안내 띠로 상태를 분명히 알림.
- 관리자 화면: 직원 입력 내용을 큰 글씨 메모 카드로, 이전/다음·화살표 키로 빠르게 넘겨 볼 수 있음.
- `prefers-reduced-motion`에서 새 애니메이션(알림 등장·반짝임) 꺼짐.
