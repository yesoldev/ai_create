# 홍보물 만들기 — 사용 가이드

> 신문에 실을 배너·전단지를 몇 번의 클릭으로 만드는 사내 도구입니다.
> 처음이어도 화면이 안내하는 대로 따라가면 됩니다.

---

## 1. 로그인

1. 인터넷 창에 주소를 입력해 접속합니다.
2. 회사에서 만들어 준 **이메일**과 **비밀번호**를 넣고 **[로그인]**을 누릅니다.
   - 비밀번호를 모르면 **관리자에게 문의**하세요. (직접 가입은 없습니다.)

## 2. 새 홍보물 만들기 (5단계)

홈 화면에서 초록색 **[새 홍보물 만들기]** 버튼을 누릅니다. 그러면 5단계로 안내합니다.

1. **종류 고르기** — 배너(가로로 긴 것) 또는 전단지(세로로 긴 것)를 고릅니다.
2. **업종 고르기** — 음식점·부동산·채용·구인 등 해당 업종을 하나 고릅니다.
3. **크기·품질** — 잘 모르면 추천된 것을 그대로 두세요.
   - 원하는 크기가 있으면 **[직접 크기 정하기]**로 가로·세로와 단위(px/mm/cm)를 넣습니다.
   - 품질을 고르면 **한 장 값**과 **앞으로 몇 장 만들 수 있는지**가 아래에 나옵니다.
4. **문구 넣기**
   - 위쪽 **빠른 시작**(구인 공고·할인 행사 등)을 누르면 설명이 자동으로 채워집니다. 고쳐 써도 됩니다.
   - 그림에 넣을 글자가 있으면 적습니다. **[문구 추천받기]**를 누르면 AI가 문구를 제안합니다.
   - 참고할 사진이 있으면 **[사진 고르기]**로 첨부하면 비슷한 느낌으로 만듭니다.
5. **만들기** — 내용을 확인하고 **[만들기]**를 누르면 30초쯤 뒤 그림이 나옵니다.

## 3. 만든 그림 다듬기 (편집기)

결과 화면에서 **[글자 넣고 꾸미기]**를 누르면 편집기가 열립니다.

- **글자 넣기** — 글자를 추가하고, 그 글자를 눌러 두 번 누르면 내용을 고칩니다. **크게/작게**로 크기를 바꿉니다.
- **네모 / 동그라미** — 도형을 넣습니다. **채우기**로 색을 꽉 채우면, AI가 깨뜨린 글자를 상자로 덮고 그 위에 다시 글자를 넣을 수 있습니다.
- **색** — 고른 것의 색을 바꿉니다.
- **되돌리기 / 다시** — 실수하면 되돌립니다.

## 4. 내려받기 (인쇄용 저장)

- **[PNG]** — 배경이 비칠 수 있는 형식(품질 좋음).
- **[JPG]** — 파일이 작은 형식.
- 신문 인쇄용은 보통 **PNG**를 권합니다. 원본 크기 그대로 저장됩니다.

## 5. 다시 쓰려면 (보관함)

- 편집기에서 **[보관함에 저장]**을 누르고 이름과 **폴더(업체명)**를 정해 저장합니다.
- 홈의 **[보관함]**에서 저장한 것을 다시 열어 **글자만 바꿔** 재사용할 수 있습니다.
- 업체마다 폴더를 만들어 정리하면 찾기 쉽습니다. (**[새 폴더]**)

## 6. 비용과 한도

- 그림을 만들 때마다 약간의 비용이 들고, **이번 달 남은 금액**이 홈에 표시됩니다.
- 한도가 부족하면 만들 수 없다는 안내가 나옵니다. 그때는 **관리자에게 문의**하세요.
- **참고 사진/비슷하게 다시 만들기**는 비용이 조금 더 듭니다.

## 7. 관리자(운영자)용

- 홈 오른쪽 위 **[관리자]** → 계정 추가, 사용 중지/재개, 월 한도 변경, 무제한 설정.
- 계정 이메일은 **실제 도메인**만 됩니다(예: `name@회사.com`).
