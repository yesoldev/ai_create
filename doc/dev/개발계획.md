# AI 이미지 생성 툴 개발계획

> 미리캔버스 대체 — 사내용 AI 배너/전단지 제작 툴
> 작성일: 2026-07-07 / 상태: 계획 확정 전 (Phase 0)

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 목적 | AI로 배너·전단지 등 홍보물을 생성하고, 템플릿으로 재사용하는 사내 툴 |
| 사용자 | 5명 이하 사내용, 관리자 초대제 계정 |
| 비용 정책 | 사용자 1인당 월 15,000원 한도 (관리자가 상향 가능) |
| 이미지 생성 | OpenAI `gpt-image-2` (2026-04 출시, 커스텀 px 사이즈·한글 텍스트 지원) |
| 인프라 | 전부 무료 티어 (서버 PC 없음) |

### 샘플 분석 (`doc/sample/`)

- **배너** (`banner/1.png`, `2.png` — 500×200급): 한글 **레터링 로고형**.
  스타일화된 한글 타이포(금색 캘리그래피, 알록달록 풍선체 등) + 장식 요소(왕관, 실루엣, 놀이터, 폭죽).
  → 글자 자체가 그래픽이므로 **AI 합성 모드**(프롬프트에 문구 주입)가 주력. 깨짐 대비 부분 재생성 필수.
- **전단지** (`leaflet/*.jpg` — 1773×3189, 세로형): **고정 레이아웃 템플릿형**.
  파란 물방울 배경 + 클립보드 흰 종이 + 검은 라운드 타이틀 박스 + 불릿 본문 + 연락처 + 포인트 일러스트 1개.
  구조는 동일하고 문구/색/일러스트만 교체됨.
  → **레이어 모드**(배경·일러스트는 AI, 텍스트는 편집 가능한 레이어)가 주력. 템플릿 재사용에 최적.

## 2. 기술 스택

| 구분 | 선택 | 이유 |
|---|---|---|
| 프론트엔드 | React + Vite + TypeScript + Tailwind CSS | 캔버스 에디터 생태계, 빠른 개발 |
| 캔버스 에디터 | **Fabric.js** | 텍스트/도형/이미지 객체 모델, 드래그 리사이즈·회전 내장, **캔버스 상태를 JSON 직렬화 → 템플릿 재사용(b)의 핵심** |
| 백엔드 | Python **FastAPI** | OpenAI SDK, 이미지 처리(Pillow), 비용 계산·한도 차단 |
| DB / 인증 / 파일 | **Supabase 무료 티어** | PostgreSQL + Auth + Storage(1GB) 통합. 부족 시 Cloudflare R2(10GB 무료) 추가 |
| 호스팅 | **Render 무료 웹서비스** | 백엔드 + 프론트 정적 빌드 함께 서빙. 15분 미사용 시 슬립(첫 접속 30초~1분) — 5명 사내용이라 감수 |
| 이미지 생성 | OpenAI `gpt-image-2` (절약: `gpt-image-1-mini`) | 커스텀 사이즈(16배수, 최대 3840px, 비율 3:1 미만), 마스크 편집, 한글 렌더링 개선 |
| 문구 자동생성 | OpenAI 텍스트 모델 (mini급) | 카피라이팅, 장당 1원 미만 |

### 참고 비용 (1024×1024 기준)
- low ≈ $0.006 / medium ≈ $0.05 / high ≈ $0.21
- 1인 월 15,000원(≈$11) ≈ medium 약 200장, high 약 50장

## 3. 기능 요구사항 및 구현 방식

### 3.1 이미지 생성
- [ ] **프롬프트 생성**: 텍스트 프롬프트 → gpt-image-2 호출
- [ ] **딸깍 템플릿**: 사전 정의 프롬프트 프리셋(업종/스타일/색상 선택 UI) → 원클릭 생성
- [ ] **이전 이미지 참고 생성**: 생성 이력에서 선택 → reference 이미지로 전달.
  유사도는 **3~4단계**(약하게/중간/강하게/거의 동일)로 제공 — 프롬프트 강도 + reference 사용 방식 조합으로 근사 (0~100% 슬라이더는 모델 한계로 불가)
- [ ] **첨부 이미지 참고 생성**: 업로드 이미지를 reference로 전달
- [ ] **지정 사이즈 생성**: 요청 px을 16배수로 스냅해 생성. 3840px 초과(대형 인쇄물)는 최대 크기 생성 후 업스케일
- [ ] **배경 템플릿**: 배경 색상/패턴 프리셋 선택 시 해당 배경 위에 생성 (edit API에 배경 이미지 깔기)

### 3.2 한글 문구 처리 (이중 모드)
- [ ] **레이어 모드 (기본, 전단지 주력)**: AI는 배경/일러스트만 생성, 문구는 Fabric.js 텍스트 레이어.
  재사용 시 글자만 교체 — 비용 0, 깨짐 0%
- [ ] **AI 합성 모드 (배너 주력)**: 문구를 프롬프트에 주입해 레터링째 생성.
  - [ ] 문구 직접 입력(주입) + AI 카피 자동생성(업종/이벤트 입력 → 문구 제안) 모두 지원
  - [ ] **깨진 텍스트 부분 재생성**: 깨진 영역을 드래그 지정 → 알파 채널 마스크 생성 → edit API 인페인팅

### 3.3 에디터 (Fabric.js 캔버스)
- [ ] 자르기(crop), 드래그 핸들 리사이즈
- [ ] **px/mm/cm 단위 사이즈 입력** — mm/cm는 DPI 기준 환산(기본 300DPI, 설정 가능). 캔버스 크기 = 생성 요청 크기와 연동
- [ ] **그리기 도구 (PPT/그림판 수준)**:
  - [ ] 텍스트 추가 (폰트·크기·색·굵기·정렬·외곽선)
  - [ ] 도형 추가 (사각형·라운드 사각형·원·선·화살표·삼각형)
  - [ ] 색상 채우기 (도형 fill/stroke, 배경색, 스포이드)
  - [ ] 자유 그리기(펜/브러시), 지우개
  - [ ] 레이어 순서(앞/뒤), 복제, 삭제, 정렬 스냅, 실행취소/재실행(undo/redo)
- [ ] **다운로드: PNG / JPG 형식 선택 제공 (필수)** — 다운로드 버튼 클릭 시 형식 선택(PNG=투명 배경 유지, JPG=파일 작음·품질 90). 인쇄용은 원본 해상도 그대로, 파일명은 `템플릿명_YYYYMMDD.png` 형식

### 3.4 계정 관리
- [ ] Supabase Auth — **회원가입 비활성**, 관리자가 계정 생성/초대만 가능
- [ ] 역할: `admin` / `user`
- [ ] 관리자 화면: 계정 추가·비활성화, 한도 조정, 사용량 조회

### 3.5 비용 한도
- [ ] 생성 요청마다 비용 계산(모델·품질·크기·참고이미지 기준) → `usage_log` 기록
- [ ] 월 누적이 한도(기본 15,000원) 도달 시 생성 차단 + 안내
- [ ] 관리자가 사용자별 한도 상향/리셋 가능, 월 1일 자동 리셋
- [ ] 대시보드에 본인 잔여 한도 표시 (예상 비용 미리보기 포함)

### 3.6 템플릿 관리 (트리)
- [ ] 트리 구조: `카테고리(배너/전단지/...) > 업체명 > 템플릿` — 폴더 자유 생성
- [ ] **템플릿 = Fabric.js 캔버스 JSON + 생성 프롬프트 + 배경 이미지 참조** 저장
  → 열면 텍스트/색/일러스트를 바꿔 재사용 가능 (요구사항 4-b)
- [ ] 생성 완료 시 트리 위치 지정해 저장, 썸네일 자동 생성
- [ ] 검색, 이동, 복제, 삭제

## 4. 화면 구성

| 화면 | 내용 |
|---|---|
| 로그인 | 이메일/비밀번호 (초대 계정만) |
| 홈(대시보드) | 최근 작업, 잔여 한도, 빠른 생성 버튼 |
| 생성 스튜디오 | 좌: 프롬프트/템플릿/참고이미지/사이즈/배경 패널 · 중: 미리보기 · 우: 생성 이력 |
| 에디터 | Fabric.js 캔버스 + 도구바(텍스트/도형/채우기/그리기) + 레이어 패널 + 부분 재생성 |
| 템플릿 보관함 | 좌: 트리 · 우: 썸네일 그리드 |
| 관리자 | 계정 관리, 한도 관리, 전체 사용량 통계 |

### UI 개발 원칙 (필수)
> **모든 UI 화면은 `/frontend-design-merged` 스킬로 생성하고, 완성 후 `/design-review` 스킬로 리뷰를 통과해야 한다.**
> 제네릭한 AI 미학 금지 — 디자인 툴답게 세련된 작업 환경 지향.

**최우선 원칙: 나이든 사용자도 쓸 수 있을 만큼 단순하고 쉬워야 한다.**
- 큰 글씨(기본 16px 이상)·큰 버튼(최소 44px 터치 영역)·높은 대비 — 모든 라벨은 쉬운 한글(전문용어·영어 금지: "프롬프트" → "만들고 싶은 이미지 설명")
- 생성은 **단계별 마법사 흐름**: ① 종류 선택(배너/전단지) → ② 템플릿 딸깍 → ③ 문구 입력 → ④ 만들기 버튼. 한 화면에 한 가지 결정만
- 고급 옵션(유사도·품질·DPI 등)은 기본값으로 숨기고 "자세히" 안에 배치
- 아이콘에는 반드시 글자 라벨 병기, 모든 파괴적 동작(삭제 등)은 확인창 + 실행취소 제공
- 에디터 도구는 그림판 수준으로 최소화해 노출 — 자주 쓰는 것(글자 넣기·도형·색 바꾸기)만 큰 버튼으로
- `/design-review` 시 "60대 초보 사용자가 설명 없이 전단지 1장을 만들 수 있는가"를 통과 기준으로 삼는다

```
users          id, email, name, role(admin|user), is_active, monthly_limit_krw(기본 15000), created_at
```

## 5.1 백엔드 API 명세 (초안)

```
[인증 — Supabase Auth 토큰을 FastAPI에서 검증]
POST   /api/auth/login              이메일/비밀번호 → 세션 토큰

[생성]
POST   /api/generate                { prompt, width, height, unit(px|mm|cm), dpi,
                                      quality(low|medium|high), bg_preset_id?,
                                      ref_generation_id? | ref_upload_id?,
                                      similarity(1~4)?, mode(layer|ai_text), text_content? }
                                    → 사전 비용 체크(한도 초과 시 402) → 생성 → Storage 저장
                                    → { generation_id, image_url, cost_krw, remaining_krw }
POST   /api/generate/inpaint        { generation_id, mask_png_base64, prompt }  -- 깨진 텍스트 부분 재생성
POST   /api/copywrite               { business, event, tone } → 문구 후보 3~5개 (텍스트 모델)
POST   /api/refs/upload             참고 이미지 업로드 → { ref_upload_id }
GET    /api/generations?user=me     본인 생성 이력 (스튜디오 우측 패널)

[템플릿 트리]
GET    /api/folders/tree            전체 트리
POST   /api/folders                 { parent_id?, name }
PATCH  /api/folders/{id}            이름 변경 / 이동
DELETE /api/folders/{id}            (내용물 있으면 409 → 확인 후 재요청)
GET    /api/templates?folder_id=    폴더 내 템플릿 목록(썸네일)
POST   /api/templates               { folder_id, name, canvas_json, prompt, size, dpi }
GET    /api/templates/{id}          canvas_json 포함 전체 → 에디터에서 열기
PATCH  /api/templates/{id}          저장(덮어쓰기) / 이동
POST   /api/templates/{id}/copy     복제
DELETE /api/templates/{id}

[사용량/한도]
GET    /api/usage/me                이번 달 사용액, 한도, 잔액
GET    /api/usage/estimate          생성 옵션 → 예상 비용 (생성 버튼 옆 표시용)

[관리자 전용]
GET    /api/admin/users             계정 목록 + 월 사용액
POST   /api/admin/users             계정 생성 (이메일, 임시 비밀번호)
PATCH  /api/admin/users/{id}        활성/비활성, monthly_limit_krw 변경
GET    /api/admin/usage?month=      전체 사용량 통계
```

### 비용 계산 규칙
- OpenAI 응답의 usage(토큰) × 단가로 USD 계산 → 고정 환율(설정값, 기본 1 USD = 1,400원)로 KRW 환산해 `generations.cost_krw` 기록
- 단가 상수는 `config.py`에 상수로 두고 주석에 출처 명시 (gpt-image-2: 이미지 출력 $30/1M tokens, 이미지 입력 $8/1M, 텍스트 입력 $5/1M — 2026-07 기준, 변경 시 여기만 수정)
- 참고 이미지 포함 시 입력 이미지 토큰도 비용에 합산 (gpt-image-2는 입력이 항상 high fidelity로 과금됨)
- 한도 체크는 **생성 전** `usage_monthly` 집계로 판단하고, 예상 비용이 잔액 초과면 거부. 관리자는 한도 무제한 옵션 가능

## 6. 개발 단계

### Phase 1 — 기반 (뼈대)

- [ ] FastAPI 백엔드 뼈대 + OpenAI 연동 + 비용 계산 모듈
- [ ] React 프로젝트 셋업, 로그인, 라우팅
- [ ] Render 배포 파이프라인

### Phase 2 — 생성 코어
